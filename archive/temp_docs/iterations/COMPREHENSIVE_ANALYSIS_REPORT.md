# 知识图谱模型选择 - 综合质量与成本分析报告

## 执行摘要

本报告基于 8 个真实对话样本对 5 个 Vertex AI 模型进行了全面测试，评估其在实体提取任务中的质量表现与成本效益。

**核心结论：Gemini 2.5 Flash 是最佳选择**
- 提取质量优于所有模型（平均 12.4 实体/对话）
- 成本极低（完整语料库预计 $33）
- 87.5% 成功率可接受（可通过重试机制提升）

## 五、最终推荐

### 🏆 推荐方案：Gemini 2.5 Flash + 失败重试机制

**理由**：
1. **质量最优**：提取实体数量最多（87个），Topics 和 Locations 覆盖最全面
2. **成本极低**：$33 处理全量数据，比 Claude Sonnet 4 省 $3,507（节省 99%）
3. **可接受的成功率**：87.5% → 通过 1 次重试可达到 98.4% 成功率
4. **细粒度优势**：更善于捕捉主题细节和地点信息，适合个人助理场景

### 重试策略设计

```python
def extract_with_retry(model: str, conversation: dict, max_retries: int = 2):
    for attempt in range(max_retries):
        result = call_gemini_model(model, conversation)
        if result['error'] is None:
            return result
        if attempt < max_retries - 1:
            print(f"Retry {attempt + 1}/{max_retries - 1}...")
            time.sleep(1)  # 短暂延迟避免限流
    return result  # 最终失败返回错误

# 预期效果：
# - 1次重试: 87.5% → 98.4% 成功率
# - 2次重试: 87.5% → 99.8% 成功率
# - 成本增加: ~15%（仅失败样本重试）
```

**预期最终成本**：$33 × 1.15 = **$38**（含重试）
